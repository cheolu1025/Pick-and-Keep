# Pick & Keep — A → B 전달 사항 (2026-11-22)

## 요약

A 쪽 함수는 전부 main에 올라가 있어서 임시 함수 없이 바로 연결하면 돼 (PR #1~#3). `git pull` 받고 아래만 챙겨줘.

- [ ] main 받기: `git checkout main && git pull` 후 내 브랜치에 `git merge main`
- [ ] `app.py`에 `db.init_db()` 한 줄 추가
- [ ] 보관함 목록·썸네일은 `get_photo_url(key, mark_viewed=False)`
- [ ] 사진 클릭 시 크게 보기 화면 만들기 (`/photo/<id>` → `db.get_photo(id)`, 여기서만 `get_photo_url(key)`)
- [ ] `/save`에서 `is_duplicate(hash)` 먼저 확인
- [ ] 메인 배너는 `get_old_hold_photos()` 인자 없이, 문구는 `hold_period_label()`
- [ ] `.env`에 새 항목 추가
- [ ] 맨 아래 질문 2개 답해주기

## 꼭 지켜야 할 4가지

이 4가지는 빠지면 오류가 나거나 기능이 조용히 안 돌아가.

| 할 것 | 안 하면 |
| --- | --- |
| `app.py`에서 앱 만든 직후 `db.init_db()` 호출 (여러 번 불러도 괜찮음) | 첫 저장에서 `no such table: photos` 오류 |
| 목록·썸네일은 `get_photo_url(key, mark_viewed=False)` | 보류함 목록만 열어도 전부 "방금 봄"이 돼서 60일 알림이 안 울림 |
| 저장 전에 `db.is_duplicate(hash)` 확인 | 같은 해시로 저장하면 `sqlite3.IntegrityError` |
| 배너는 `db.get_old_hold_photos()`를 인자 없이 호출 | 시연 모드(2분)로 바꿔도 배너가 60일 기준에 멈춰 있음 |

크게 보기 화면이 없으면 열람 기록이 아예 안 남아서, 보류함 사진이 전부 60일 뒤에 알림 대상이 돼. 사진 클릭 → 크게 보기는 꼭 넣어줘.

## 화면별 사용법

변수 이름(`r["hash"]` 등)은 예시야. 네 `result.json` 필드명에 맞춰서 써줘.

**앱 시작 (`app.py` 위쪽)**

```python
import db, aws_utils

app = Flask(__name__)
db.init_db()
```

**`/save` — 사진 저장**

```python
for r in selected_photos:          # result.json에서 사용자가 고른 사진들
    if db.is_duplicate(r["hash"]):
        skipped.append(r)            # 화면에 "이미 보관함에 있는 사진이에요"
        continue
    key = aws_utils.upload_photo(r["jpg_path"], folder)   # folder: "keep" | "hold", 원래 해상도 JPG
    db.save_photo_record(r["original_name"], key, folder,
                         r["labels"], r["original_size"], file_hash=r["hash"])
```

**`/keep`, `/hold` — 보관함 목록**

```python
photos = db.get_photos("hold")      # 최신순
for p in photos:
    p["url"] = aws_utils.get_photo_url(p["s3_key"], mark_viewed=False)
```

**크게 보기 — 여기서만 열람 기록**

```python
@app.route("/photo/<int:photo_id>")
def photo(photo_id):
    p = db.get_photo(photo_id)         # 목록에서 <a href="/photo/{{ p.id }}">
    if p is None:
        abort(404)
    url = aws_utils.get_photo_url(p["s3_key"])  # 기본값 = 열람 시각 갱신
    return render_template("photo.html", photo=p, url=url)
```

화면끼리 사진을 주고받을 때는 `s3_key` 말고 **`id`(사진 번호)**를 넘겨줘. 사진을 평생 보관함으로 옮기면 `s3_key`는 `hold/...` → `keep/...`로 바뀌지만 `id`는 그대로라서, 주소나 버튼이 깨지지 않아. 라우트 이름은 네가 정하면 돼.

**`/stats` — 확보 용량**

```python
saved_bytes = db.get_saved_size()  # 바이트, MB 표시는 화면에서 변환
```

**메인 배너 — 오래 안 본 보류함 사진**

```python
old = db.get_old_hold_photos()     # 인자 없이! .env 기간(60일 / 시연 모드 2분)을 따름
if old:
    banner = f"{db.hold_period_label()} 동안 안 본 사진이 {len(old)}장 있어요"
```

**보류함 버튼 3개** — 버튼은 `id`를 넘기고, 받은 쪽에서 `key = db.get_photo(photo_id)["s3_key"]`로 꺼내 써.

| 버튼 | 호출 |
| --- | --- |
| 삭제 | `aws_utils.delete_photo(key)` → `db.delete_photo_record(key)` |
| 기간 연장 | `db.update_last_viewed(key)` |
| 평생 보관함으로 | `new_key = aws_utils.move_photo(key, "keep")` (새 key 반환, DB도 자동 갱신) |

## 사진 정보와 오류

`get_photos`, `get_photo`, `get_old_hold_photos`, `is_duplicate`는 사진마다 아래 키를 가진 dict를 돌려줘. 없는 번호로 `get_photo`를 부르면 `None`이야.

| 키 | 내용 |
| --- | --- |
| `id` | 사진 번호 |
| `filename` | 원본 이름 (한글 가능) |
| `s3_key` | S3 위치, 다른 함수에 넘길 때 쓰는 값 |
| `folder` | `"keep"` 또는 `"hold"` |
| `labels` | `[{"name": ..., "confidence": ...}]` 리스트 (JSON 문자열 아님) |
| `size` | 원본 크기 (바이트) |
| `uploaded_at`, `last_viewed` | UTC ISO 문자열, 예: `2026-11-22T09:00:00+00:00` |
| `file_hash` | 원본 SHA-256 (안 넘겼으면 None) |
| `status`, `notified_at` | A 내부용, 무시해도 돼 |

날 수 있는 오류는 3가지야.

- `sqlite3.IntegrityError`: 같은 `file_hash`를 두 번 저장할 때
- `ValueError`: folder가 `keep`/`hold`가 아닐 때
- `RuntimeError`: `.env`에 `S3_BUCKET_NAME`이 비어 있을 때

## .env 추가 항목

네 `.env`에 아래 5줄을 추가해줘. 비워 둬도 기본값(60일, SQS 끔)으로 동작해. `.env.example`에도 들어 있어.

```
USE_SQS=false
SQS_QUEUE_URL=
HOLD_DAYS=60
HOLD_DEMO_MINUTES=
SITE_URL=
```

- `S3_BUCKET_NAME`은 네 계정의 테스트 버킷 이름
- `HOLD_DEMO_MINUTES=2`를 넣고 Flask를 재시작하면 시연 모드. 보류함에 넣고 2분 뒤 배너가 뜨는지 네 컴퓨터에서도 테스트할 수 있어
- `.env`는 Flask 시작 때 읽으니까 값을 바꾸면 재시작해야 반영돼. 서버에서는 내가 켜고 끌게
- 알림 메일(SNS)은 서버에서 1분마다 자동으로 돌고 사진마다 한 번만 보내. 네가 할 건 없어

## SQS

SQS는 네가 제안한 `result.json` 방식으로 가. DB 쪽 SQS 함수(`update_classification`, `get_status`)는 만들지 않았고, `status` 열은 남아 있지만 항상 `done`이야.

- **실제 서비스용 큐는 내 계정에 내가 만들게.** EC2가 내 계정에 있어서 네 계정 큐에는 접근이 안 돼. 네 큐는 테스트용으로 쓰고, 코드에서 큐 URL은 `.env`에서만 읽어줘
- **워커 systemd 등록도 내가 할게.** 워커가 완성되면 실행 명령(예: `python3 worker.py`)과 필요한 `.env` 항목을 알려줘
- **권장:** 워커가 `result.json`을 쓸 때 임시 파일에 먼저 쓰고 `os.replace`로 바꿔치면 `/status`가 쓰다 만 파일을 읽지 않아

```python
tmp = path + ".tmp"
with open(tmp, "w", encoding="utf-8") as f:
    json.dump(result, f, ensure_ascii=False)
os.replace(tmp, path)
```
