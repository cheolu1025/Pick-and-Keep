# 첫 화면 기본 사진

첫 화면 오른쪽 필름 칸(6칸)에 쓰는 기본 사진. **폴더 하나가 한 묶음**이다.

```
static/sample/
├── city/   (도시 산책: sample_01.jpg ~ sample_06.jpg)
└── warm/   (따뜻한 일상: sample_01.jpg ~ sample_06.jpg)
```

- 평생 보관한 사진이 있으면 그 사진이 먼저 나오고, 6장보다 적으면 나머지 칸을 기본 사진으로 채운다.
- 묶음이 여러 개면 첫 화면을 열 때마다 번갈아 보여준다. 폴더를 하나 더 만들면 묶음이 늘어난다.
- 칸 순서: 01 왼쪽 위(가로), 02 오른쪽 위(가로), 03 왼쪽 가운데(세로), 04 오른쪽 가운데(세로), 05 왼쪽 아래(정사각), 06 오른쪽 아래(정사각)
- JPG 또는 PNG, 긴 쪽 1000px 정도로 줄여서 넣는다 (첫 화면이 느려지지 않게).
- 레포가 Public이므로 **직접 찍은 사진**이나 **무료 사용이 허락된 사진**(Unsplash, Pexels 등)만 넣는다.
  인터넷에서 저장한 사진(핀터레스트 등)은 저작권 문제가 있어서 넣으면 안 된다.
